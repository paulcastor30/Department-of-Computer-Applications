11. **No additional same-person duplicate degree pairs found** in the accessible data beyond Alce’s two suspected pairs. Different bachelor’s/master’s titles for the same person are retained separately; common MSCA qualifications across different faculty are not duplicates. Fellowships/internships remain academic experience, as explicitly supplied.

The importers match on exact `degree_name` plus `institution` (0004 lines 344–347; 0009 lines 235–236). Wording changes can create a second record without reconciling an older one. This is a plausible contributor to Alce’s duplicates, not evidence that any particular version is correct.

## Proposed compact public design

- Keep the existing Educational Attainment heading, framework, profile URLs and page navigation. Use a single list with thin row separators rather than individually bordered cards. No fixed-height rows.
- Each row: wrapping qualification title in semibold, followed by one muted institution/location line. A four-digit completion year sits at the right on wide screens and underneath on narrow screens. Use 12px vertical row spacing, 14–16px readable text and approximately 1.5 line height. No title truncation.
- Show Completed qualifications and Ongoing study headings only when department-approved records exist in each group. Verified completed qualifications without a supplied year omit the year; they do not become ongoing. Verified ongoing records show no completion year. All records stay visible, including long lists.
- Internal review records, review notes and confirmation headings are absent from public API responses as well as the page. Preserve original records and evidence internally. Do not rely on CSS hiding.
- Fellowships and internships appear in a separate compact Academic experience list because the supplied sources explicitly distinguish them from degrees.
- Canonical institution display uses approved institution identity plus location once; remove redundant country repetitions. Preserve unknown locations as empty. Do not infer campuses from university names.
- Replace note-pattern status inference with explicit department-approved status/verification metadata. Existing rows default to review until assessed; no automatic migration from year presence to verified. Keep the Django-backed record flow and publication controls.
- Maintain an internal relationship between a confirmed canonical record and its original source entries; only after identity is confirmed, retire redundant public entries through reversible publication flags. No deletion or uniqueness constraint based merely on title/institution text.
- Review the independent Highest completed qualification summary in directory and profile overview against approved completed records; no automatic promotion from ongoing doctoral study. Also prevent legacy educational_background from re-exposing held qualifications when public structured records are empty.

See [standalone layout proposal](layout-proposal.html). It uses fictional placeholders and changes no site code or data.
