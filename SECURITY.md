# Security reports

Do not post vulnerabilities, passwords, or private records in public issues.

A private security reporting contact has not been published yet. The maintainer needs to add a contact here or enable GitHub private vulnerability reporting.

When a private channel is available, include the affected page or component, what happened, and steps to reproduce it using test data. Do not include other people's records.

For ordinary bugs that do not expose sensitive information, use [Issues](https://github.com/paulcastor30/Department-of-Computer-Applications/issues).
